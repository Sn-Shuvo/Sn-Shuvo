## Featured Project

### DengResQ — Dengue Response & Community Health Platform
*Private repository, in active development*

A full-stack civic health platform built to support dengue outbreak response in Bangladesh, with five distinct portals:

- **Citizen** — symptom checks (AI-assisted), breeding site reporting, gamified engagement (badges, quests, seasonal leaderboards)
- **Donor** — blood donation matching and appointment scheduling
- **Health Officer** — field team dispatch, breeding site mapping, area alerts
- **Hospital** — patient records and blood request management
- **Institution** — university cohort management and public dengue-response rankings

**Stack:** PHP, MySQL, JavaScript &nbsp;|&nbsp; **Highlights:** 70+ table normalized schema (3NF), OTP-based auth, role-based access control across five user types
